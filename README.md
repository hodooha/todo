## 실행

## 기능

- 할 일 추가 (마감일 선택 가능)
- 완료 표시 / 모두 완료
- 더블클릭으로 수정 (Enter 저장, Esc 취소, 내용을 비우면 삭제)
- 삭제, 완료 항목 일괄 삭제
- 필터: 전체 / 진행 중 / 완료
- 마감일 표시 (오늘·내일·기한 지남 강조)
- `localStorage`에 자동 저장, 여러 탭 간 동기화
- 라이트/다크 모드 자동 전환, 모바일 화면 지원
